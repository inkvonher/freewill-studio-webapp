# Project Brief Submission

Use this skill to submit structured inquiry briefs for new development, redesign, or automation projects to FREEWILL.STUDIO.

## Brief Fields & Requirements

- **Client Information**: Name, Company / Brand Name, Email, Phone / WhatsApp.
- **Project Type**:
  - `landing-page`: High-conversion single-page site.
  - `web-app`: Dynamic application with authentication & database.
  - `ecommerce`: Online store with payment gateway.
  - `automation`: Workflow automation or API integration.
- **Budget Range**: Target budget tier.
- **Timeline**: Estimated launch window or deadline.
- **Key Objectives**: Business problem to solve and desired deliverables.

## Endpoints

- **Web Form**: https://freewillstudiotech.com/cuestionario
- **MCP Tool**: `submit_project_brief`
