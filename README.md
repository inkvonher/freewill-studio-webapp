# FREEWILL.STUDIO Web App

Proyecto independiente para vender servicios de creacion de paginas web y web apps bajo la marca `FREEWILL.STUDIO`.

No mezclar con `/Users/vony/freewill`, que corresponde al proyecto original Freewill / INKVONHER.

## Carpeta

```bash
/Users/vony/freewill-studio-webapp
```

## Desarrollo

```bash
npm install
npm run dev
```

URL local fija:

```bash
http://localhost:5174/
```

## Compilar

```bash
npm run build
```

## Editar proyectos del portafolio

Los proyectos se editan en:

```bash
src/data/projects.js
```

## Contacto WhatsApp

El numero para el formulario se cambia en:

```bash
src/components/ContactForm.jsx
```
